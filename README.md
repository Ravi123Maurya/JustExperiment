# JustExperiment 🎨

A playground project where I explore and experiment with **Kotlin** and **Jetpack Compose**.  
This repository is not a polished app, but rather a collection of ideas, prototypes, and experiments with various concepts, animations, and UI components.

---

## ✨ What’s Inside
- Experiments with **Jetpack Compose layouts** and modifiers
- Custom **animations** and transitions
- Reusable **UI components**
- Snippets for learning and testing new **Kotlin features**
- Small demos to understand **Compose graphics** and **Canvas drawing**

---

## 🎯 Purpose
This project serves as:
- A **learning ground** for trying out new Compose APIs
- A **reference library** of code snippets and patterns
- A **sandbox** for testing ideas before using them in real apps
